zonZ Android Launcher

**HorizonZ Android Launcher** adalah launcher modern dan berkinerja tinggi untuk menjalankan Minecraft: Java Edition (26.3) di perangkat Android, dibuat dengan 100% Rust dan antarmuka Zalith Material 3 (M3) UI.

## Fitur Utama

- **100% Native Rust Engine**: Performa tinggi dan efisiensi memori teroptimalkan untuk arsitektur ARM64 / Android.
- **Upstream Core**: Berbasis `horizon-rust/horizon` (v0.2.97) dengan dukungan penuh untuk Minecraft Java Edition 26.3.
- **Zalith M3 UI**: Antarmuka pengguna modern berstandar Material Design 3 yang responsif dan intuitif.
- **Manajemen Akun & Sesi**: Dukungan login cepat, pengelolaan profil, dan pengaturan alokasi RAM/Java runtime secara kustom.
- **Optimasi Kontrol Sentuh**: Kontrol virtual yang terpersonalisasi untuk pengalaman bermain di layar sentuh Android.

## Informasi Rilis Terbaru

- **Versi**: v0.7.4 (Build #4)
- **Engine Core**: Rust 26.3 + Zalith M3 UI
- **Upstream Engine**: horizon-rust/horizon v0.2.97
- **Target OS**: Android 8.0+ (ARM64)

## Instalasi & Penggunaan

1. Unduh file APK versi terbaru dari tab Releases.
2. Pasang APK di perangkat Android Anda.
3. Buka aplikasi HorizonZ Launcher.
4. Masuk dengan akun Anda dan sesuaikan pengaturan memori (RAM) serta kontrol.
5. Klik **Play** untuk memulai perma
